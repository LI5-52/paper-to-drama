# 论文事实—解释—虚构边界

## 四层标签（每条关键语句或关键情节可关联）
1. `supported_claim`：论文直接报告且在正确的对象、场景、证据强度内表述的研究发现。必须记录 `source_locator`。
2. `source_question_or_hypothesis`：作者提出的研究问题或假设。允许形成悬念，禁止写成“已证实”。
3. `interpretive_bridge`：将研究现象通俗化、类比化或转化成日常问题，需标注是解释而不是论文原话。
4. `fictional_plot`：人物、对白、事件、世界规则、结局等创作内容；可较自由，但不可借故事镜头宣称论文证明了其虚构后果。

## 审查决策
- 明显反转或巨大风险若依赖研究尚未支持的极端效果，优先改写成虚构世界规则并在片尾/详情保持论文来源及改编说明，不在剧内滥用“研究证明”。
- 不应只靠将确定句改成疑问句就自动放行；如果所有镜头暗示同一夸大结论，仍须修改。
- 对敏感应用（健康/灾难/公共风险）提升审查：不以虚构案例诱导现实行为决策。
- 向观众显示论文题目/来源的可选引导卡，说明“根据论文议题进行虚构改编”；如有事实说明必须依据原文。

## 事实追踪方法
`evidence_id` → `research_card_id` → `seed_id` → `beat_id`（必要时）→ `scene_id/shot_id`。不要求每条虚构对白映射论文段落，仅**声明了研究事实**或决定改编边界的内容需要精确依据。

参考：PaperTok 的可信传播讨论 https://arxiv.org/html/2601.18218 ，科学事实与虚构情节之间的具体四层设计是本项目提出，仍需开展误解实验。
